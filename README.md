### 📌 Sobre mim

Olá! Sou o **Daniel Gomes de Paula**, um desenvolvedor apaixonado por tecnologia, lógica e soluções práticas. Atualmente estou no último ano do Ensino Médio e também cursando o **Técnico em Análise e Desenvolvimento**. Gosto de transformar ideias em projetos reais, aprender novas tecnologias e melhorar constantemente como profissional.

Meu foco está em:

- Backend com Java e Spring Boot
- APIs REST com Python e FastAPI
- Banco de dados MySQL
- Desenvolvimento de aplicações práticas e funcionais
- Aprendizado contínuo em arquitetura, testes e boas práticas
